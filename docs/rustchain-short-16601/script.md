# Script — RustChain in under 60 seconds

**Hook**

Can a laptop from 2003 get a bigger mining multiplier than a modern workstation? RustChain’s own documentation says yes — by design.

**Narration**

RustChain describes itself as a DePIN network built around Proof of Antiquity: instead of treating old hardware as a disadvantage, its reward model gives vintage machines larger multipliers. The project README says a PowerBook G4 from 2003 gets a 2.5× multiplier relative to the modern Threadripper example it uses.

The project also says it checks physical-machine signals such as oscillator drift, cache timing, SIMD identity, thermal entropy and instruction jitter to help distinguish real hardware from virtualized copies.

The idea is unusual: keep working computers useful longer, and make age part of the network’s value proposition.

Don’t take the headline on faith — open the source, inspect the rules, and test the hardware claims yourself.
