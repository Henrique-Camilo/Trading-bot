# Storyboard — vertical Short (≤60s)

## 0–5s — Hook
Vertical 9:16 title card: **“2003 PowerBook > modern workstation?”**
Subline: **“RustChain’s multiplier claim — check the source.”**

## 5–17s — Show the first-party claim
Screen capture the RustChain README section that states a PowerBook G4 from 2003 receives a 2.5× multiplier in its comparison example. Keep the repository name and URL visible. Highlight only the exact line being narrated.

## 17–32s — Explain the mechanism
Simple vertical diagram:
`Real machine → hardware fingerprint checks → Proof of Antiquity → reward multiplier`
Do not animate or imply a successful mining result for Henrique.

## 32–45s — Physical-signal list
On screen, one at a time: oscillator drift; cache timing; SIMD identity; thermal entropy; instruction jitter. Caption: **“Signals named in RustChain’s first-party README.”**

## 45–54s — Why the project says this matters
Show an old laptop/desktop using either original footage, rights-cleared media, or a generated neutral illustration. Overlay: **“Preserve working hardware instead of treating age only as a liability.”**

## 54–60s — Verification CTA
End card: **“Read the source. Check the rules. Test the claims.”**
Small disclosure: **“Agent-prepared package; no mining/reward result claimed.”**

## Production constraints
- No copyrighted third-party clips without permission.
- No invented hashrate, earnings, user wallet balance or payout screenshot.
- No implication that simulation or documentation equals real mining.
- If the README changes before publication, re-check every numerical claim against `SOURCES.md`.
