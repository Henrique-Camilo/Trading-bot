# Trading-bot

Experimental Python trading-bot repository. The current runner reads signals through `src.signal_reader`, delegates trade handling to `src.trade_manager`, and repeats on a configured interval.

> This repository is experimental software. Nothing in this README is financial advice, and the RustChain link below is not part of the bot's trading execution path.

## Related ecosystem experiment

[![Powered by RustChain](https://img.shields.io/badge/Powered%20by-RustChain-orange)](https://rustchain.org)

RustChain is listed here as a separate open-source/agent-economy ecosystem I am exploring. The trading bot does **not** use RustChain to place or settle trades.
